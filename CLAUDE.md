# CLAUDE.md

The conventions for this repository live in **[AGENTS.md](AGENTS.md)**. Read it
before writing code, prompts, docs, or commit messages here.

It covers:

- **Language policy** — English is the target language; Chinese is read-only
  legacy. This is the rule most likely to be violated by accident, because much
  of the codebase still carries Chinese from before the policy.
- **Answer structure** — how to reason through a technical question in this repo.
- **TypeScript practice** — boundary narrowing, domain modeling, where
  legal-state constraints live, and evolution safety.

This file exists only to point there. Do not duplicate the conventions here —
one source, so the two cannot drift.
